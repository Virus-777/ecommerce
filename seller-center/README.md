# Marketly Seller Center (`@marketly/seller-center`)

For seller owners and seller staff: setup guide, dashboard, products and offers (catalog match, new product, create offer), inventory and bulk updates, orders and shipping, returns and cases, finance and statements, marketing and sponsored campaigns, customer messages, reports, account health, store profile, staff and permissions, notifications and help.

```
npm run dev:seller     # from the repository root → http://127.0.0.1:3001
```

Pages are in `src/pages/`; the layout (`SellerLayout`) and everything else shared is in [web-shared](../web-shared/README.md). Conventions: [web-shared/docs/PORTING.md](../web-shared/docs/PORTING.md).
